Spec Formatter

Format construction specifications by architect standard.

This site hosts a Microsoft Word add-in. There's nothing to use on this page directly — the tool runs inside Word.

  1. Install the add-in (beta package or your organization's deployment).
  2. Open a specification document in Word.
  3. Click Spec Formatter on the Home ribbon to open the pane.
