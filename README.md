# Spec Formatter: hosted files

This repository holds only the static web files for the **Spec Formatter** Microsoft Word add-in
(Systems West Engineers, internal tool). GitHub Pages serves them; Word loads them when the
add-in's task pane opens.

- **Generated.** The files are built and published automatically from a private source
  repository. Do not edit them here; changes are overwritten on the next publish.
- **No source code** is kept here.
- **Not a website to use directly.** The add-in runs inside Word. The home page only explains that.
- **Internal use only.** No license is granted for reuse.
